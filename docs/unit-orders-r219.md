# R219 기존 부대 명령 표시 후보

현황의 이전 표시는 도시 dest 또는 건설만 사용해 시설공격·보수이동이 있어도 '부여된 목표 없음'을 표시했다. 부대 상세에는 현재 목표 자체가 없었다. 새 순수 표시 함수는 기존 원본 명령필드를 읽으며 저장·명령을 바꾸지 않는다.

도시목표/시설공격/보수이동/보수중/건설중/지점이동/목표없음을 구분한다. 남은 경로는 배열 길이이며 도착 턴이나 실제 이동 가능성, 정지 원인을 보장하지 않는다. 목적 대상이 사라지면 확인 필요라고 표시한다. 이동이 새로 지정된 뒤 아직 정리되지 않은 건설·보수 필드는 활성 이동보다 앞서 표시하지 않는다. 시설공격 우선순위는 엔진 stepUnit과 맞춘다.
