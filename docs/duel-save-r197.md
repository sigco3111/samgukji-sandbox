# R197 일기토 저장 복원

- 진행 중 일기토의 부대 ID, 참가 무장, 합, 체력, 기력, 방침, 교체 상태와 로그를 같은 자동저장에 포함한다.
- 불러오기에서 정본 부대와 무장 상태 정리 뒤에 참조를 연결한다. 유효하지 않은 정보는 결과를 적용하지 않고 안내한다.
- 구 저장의 필드 없음/null은 대결 없음으로 처리한다. 매 수동 합 진행 뒤 저장한다. 저장 실패는 기존 안내와 재시도를 유지한다.
- 전투 산식, 난수, AI 방침 및 위임 속도는 바꾸지 않는다. 실시간 진행, 자유 교체, 설전 저장은 이 변경의 완료 범위가 아니다.
- 저장 로직은 duel-save.js의 두 순수 직렬화/검증 함수와 Game의 짧은 위임 메서드로 분리한다. 별도 저장이나 저장 후처리를 하지 않는다.
- 전체 회귀 테스트의 data-URL 비교 로더는 새 상대 import를 절대 파일 URL로 변환한다. 비교의 기존 경로 규칙은 그대로다.
- 로컬 집중 45개 검사 및 전체 45개 테스트 통과. 화면 복원 검증과 최종 커밋 정본 대조는 출시 전에 별도로 수행한다.
