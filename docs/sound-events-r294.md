# R294 로그 상한 이후 효과음 누락 수정 후보

R291의 음향은 이전 logs.length를 인덱스로 기억했다. 로그가200개에 도달하면 새 전법·계략·함락·대결 기록이 하나 들어오고 오래된 기록이 하나 지워져도 길이가 그대로200이다. 따라서 새 로그 slice가 빈 배열이 되어 효과음이 나지 않았다. 기존 함수 추출 및 실제 브라우저의 동일200로그 진단 모두에서 재현했다.

이전 길이 대신 이전 로그 객체 집합으로 새 객체를 고른다. 매 refresh에서 집합을 현재 유지로그로 교체하여 최대200개만 보유한다. 음향 끔 중에도 새 로그를 소비해 나중에 뒤늦게 재생하지 않는다. 동일 새로그 중복 refresh는 재생하지 않는다. 기존 효과음 종류별 우선순위·합성 파형·기본음소거·곡·설정 저장은 그대로다. 원문 연출 범위의 기존연결 결함 수정이며 새 음향설계가 아니다.
