# R220 대결 종료 결과 표시 후보

일기토·설전 최종 합은 기존에 즉시 닫히고 하단 로그로만 결과를 읽었다. 기존 엔진이 종료·효과 적용·저장한 뒤 표시 전용 aside에 승자/무승부/퇴각과 마지막 체력·논리, 합수를 남긴다. 결과를 다시 계산해 적용하거나 확인 버튼으로 결정 큐를 지연하지 않는다. 닫기는 화면만 지우고 저장하지 않는다. 새 결과가 오면 이전 결과를 교체한다. 저장/새로고침 뒤 과거 결과를 재구성하지 않는다.

결과는 nonmodal/포커스 강제이동 없음/z-index30이고 기존 결정 모달50 아래에 있다. 대기 외교가 있으면 기존 모달이 즉시 열리며 결과 패널은 뒤에 남는다. 결과 패널이 다른 지도/상세 일부를 덮을 수 있고 닫기로 치울 수 있다. 모든 배치/물리폰 가독성을 보장하지 않는다.

## 증거
- 69/69 suite, 새 순수 결과9assert.
- 별도 linkedom+실제 Game 대결 마운트12assert: 두 종류 종료1회/저장1회/finish1회, 대기친선 유지, 낡은 버튼 재실행무효, 닫기게임불변, 결과교체1개. 이 별도 도구는 개발환경의 의존성으로 실행했으며 repo smoke에는 의존성 추가하지 않았다.
- 격리 준비fixture 실제 UI 자동위임 클릭. 일기토18합 장료체력2/상대0 승리, 다른 PC실행은 양쪽0 무승부, 설전14합 장료논리7/상대0 승리. 매 실행 난수는 달라 결과 동일성을 주장하지 않는다.
