## 자체배치 규칙
도시 소유목록은 명시한 자체 설계다. 유비200의 수춘 등은 역사상 정확한 소재를 뜻하지 않는다. 현행 42도시만 쓰는 게임의 플레이용 축약이다. 각 세력의 기존190/가상251 관련 가문 명단을 합친 뒤 해당 연도 등장 전/사망 후 무장을 제외했다. 일부 이름있는 이동은 명시 목록으로 덮고, 나머지 당시 활동가능 무장은 기존 데이터 소재 도시 소유에 맞춰 배치(4분의1은 재야 보존)했다. 따라서 개별 소속을 고증 사실로 안내하면 안 된다. 기존 이름이 불확실한 무장은 그대로 보존했고 재명명/새초상 생성은 없다.

도시별 병력은14000~20000,225는+4000. 금4500/식량85000, 창70%·극/노50%·군마40% 해당 도시병력. 강남/형주 일부도시에 주가2/누선1. 실제 역사 병력·재정 수치가 아니다. 각 소유 도시에 한명 이상 배치, 태수는 배치자 정치 최고, 군주는 세력 첫도시. 200/208 황제는 허창 조조 보유,225는 황제시스템 없음. 184/190의 기존 낙양과251 무황제 규칙은 유지.

## 저장·시작
세 데이터 선로드/시나리오 선택카드/군주 선택을 연결했다. 새게임 기존저장 덮어쓰기 확인은 그대로 유지. 추가 데이터에 emperorCity를 지정하면 생성자에서 반영한다. 저장 형식 추가는 없고 scenId=200/208/225와 기존 전체상태 저장을 쓴다. 구세이브 시나리오 데이터와 기존 저장읽기 코드는 바꾸지 않았다.
