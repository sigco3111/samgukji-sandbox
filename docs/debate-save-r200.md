# R200 설전 저장 복원

진행 중 설전의 무장ID, 논리, 화술쿨다운, 봉인, 합, 로그 및 협상 맥락을 같은 자동저장에 포함한다. 이미 낸 비용을 재차감하지 않는다. 기존 저장의 필드없음/null은 설전 없음이다. 잘못된 상태/맥락은 협상 결과 없이 안내하고 거절한다.

- 제의 세력의 소유도시와 참가 무장, 상대 세력 생존/소속, 등용 대상의 현재 적합성을 확인한다. 카드 쿨다운은 기존 코드가0이하로 감소하므로 허용 범위를 -14까지 유지한다.
- 수신 동맹/정전 거절 뒤 설전은 reoffer 맥락을 보존한다. 제의측 승리여도 자동 성립하지 않고 다시 사용자 결정으로 이어진다.
- 수동 카드마다 저장하며 자동 결착 뒤에도 저장한다. 완료 객체의 반복 finishDebate는 효과/재결정 큐를 중복 적용하지 않는다. AI 즉시 결착/확률/비용/보상 수치는 바꾸지 않는다.
- 결착 뒤 재결정 큐가 남으면 곧바로 다음 외교 모달로 이어진다.

로컬 집중64개, 전체48개 회귀, R199대비3시나리오×3seed×150턴 저장 대조9쌍 일치(새 필드 제외). 재야/포로/타세력 등용 복원·자기부담 재차감 없음·중복효과 없음 및 직접동맹/정전/재결정 검사 포함. 실제 화면 검증과 정본 대조는 공개 전에 별도로 수행한다. 물리폰/자연발생 모든 협상/연출 강화는 완료 범위가 아니다.

## 실제 앱 검증 (격리된 준비 fixture)

PC1합 가후90/진궁100·강변쿨2,390px2합 가후60/진궁100·도발쿨3·진궁봉인을 실제 카드로 진행했다. 각각 새로고침·이어하기 전체 저장JSON이 같았고 도시·세력 자원·턴도 그대로였다. 자동 결착에서 저장이 직전 합에 남는 UI누락을 발견해 자동 버튼에도 결착 뒤 저장을 추가했다. 수정본에서 진궁 승리 후 설전null·재결정큐1개·동맹없음을 확인했고 새로고침 뒤 같은 재결정 모달/전체 저장 일치, 명시적 수락 뒤에만 동맹Until25·큐0개, 재새로고침에서 저장일치·모달없음까지 확인했다. 화면은PC와390px에서 직접 검토했으며 실폰이 아니다. 준비fixture는 공개 전 삭제한다.
