# R201 필수결정 모달 순서

실제 fieldBattle 경로로 일기토를 만들고 수신 외교 큐를 추가했을 때 둘이 공존함을 확인했다. 기존 refreshAll은 일기토 모달 다음 외교 모달을 연속 표시하여 일기토를 덮었다. 세계 턴은 이미 올바르게 차단했다.

이 변경은 표시 순서만 일기토→설전→수신 외교로 통일한다. refreshAll, 외교 결정 후속, 저장 이어하기가 같은 라우터를 사용한다. 각 결착은 남은 필수결정으로 이어지며 이미 수행한 비용/결과를 다시 적용하지 않는다. 설전 진입은 이전 일기토 UI 타이머를 정리한다. AI·확률·피해·외교/경제 수치는 변경하지 않는다.

집중39개:8개 조합별 우선순위,실제fieldBattle+수신큐,세계턴차단,결착후다음결정,라우팅무효과,화면소스연결,공존저장전체JSON복원7개(일기토+수신큐→결착→새로고침→명시수락→재새로고침·중복ID효과방지). 종료/멸망이 수신외교 큐에 가려지는 기존 경로도 원본 함수로 재현하여 종료·미응답멸망 우선으로 보호했다. 종료/멸망 DOM마운트8개에서 모달/선택버튼·타이머정리·큐유지를 확인했다. 실제DOM마운트18개:일기토자동결착UI,시작타이머와재표시정리,결착후설전/외교,명시수락관계+12,큐보존. 로컬 전체49/49·3시나리오×3seed×150턴 R200저장대조9쌍 일치. 브라우저 실제 검증과 정본 대조는 미완이다. GitHub 승인 로그인은 성공했으나 persist세션 반납 후 새세션이 로그인으로 돌아와 원격 업로드 전 보류했다. 추가 승인 재요청은 하지 않았다. 실폰/자연발생 전체조합을 검증했다고 보지 않는다.

저장실패8개: 결착 후 quota오류에서 마지막 정상 디스크는 그대로, 메모리 결착/큐 보존, 재결착효과 없음, 재시도 최신저장, 외교수락후 실패/중복ID무효/재시도 큐0개를 확인했다. 실패 직후 브라우저 강제종료로 아직 저장하지 못한 진척을 보존한다고 보장하지 않는다. 기존 저장실패 경고/타이틀이동차단은 R181 근거이며 이번 실제 화면검증은 아니다.
