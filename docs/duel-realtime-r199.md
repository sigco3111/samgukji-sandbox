# R199 실시간 일기토 UI

원기획62행의 실시간 방침 변경을 UI 타이머로 연결한다. 전투 엔진·AI·지원·난수 산식은 바꾸지 않는다. 시작/복원 시 정지, 시작 버튼 후 약1.2초마다1합은 자체 UI 속도다. 정지/한합/즉시 위임을 유지한다. 자유교체는 정지 중 가능하다.

- 진행 중 네 방침을 변경하고 즉시 저장한다. 연속방침/투지 등 효과는 기존 합 엔진에서만 계산한다.
- 필살 선택은 다음 합 대기이며 재선택하면 취소한다. 필살 대기는 저장하지 않는다. 새로고침 시 정지/대기해제를 화면에 알린다.
- 숨김 이벤트, 비활성 대결, 저장 실패 시 타이머 정지. 뒤늦은 합 몰아치기 없이 한 번씩만 예약한다. 타이머는 UI에만 있고 AI 즉시 대결에는 없다.
- 조작 버튼은 매합 유지해 포커스가 사라지지 않게 한다. 체력·투지는 별도 라벨 행으로 표시한다.

검증: 타이머17개, DOM 마운트11개 별도 검사, 전체47개 회귀 통과. R198 대비3시나리오×3seed×150턴 저장 대조9쌍 일치. DOM 검사는 주입 타이머/실제 엔진을 사용한 로컬 검사이며 실제 브라우저 화면 증거와 구분한다.

실제 앱 준비 fixture는 R198과 같이 왕윤 체력25/통제난수로 여포 참전을 발생시켰다. 자연 발생 대결 또는 물리폰 검증이 아니다. PC 시간 경과로1→6합 후 정지/새로고침/이어하기 시 전체 저장 동일. 390px 실시간 중 투지 방침 변경 후11합 정지, 필살 대기와 새로고침 뒤 대기해제/정지/저장 동일 확인.14→15합 한합에서 필살기12피해 및 투지238→158, 대기해제 확인. 위임 결착 뒤 새로고침/이어하기 저장 동일·모달 없음 확인.

숨김탭은 새 탭을 열어도 document.hidden=false로 나타나 실제 브라우저 검증 불가였다. 숨김 이벤트와 취소는 주입 검사 근거만 있으며 제한을 숨기지 않는다. 임시 준비 페이지는 출시 전 삭제한다. 설전 저장/물리폰/모든 자연 대결 경우/연출 강화는 완료 범위가 아니다.
