# R198 기참전 무장 자유 교체

## 범위
원기획65행 및 공식 매뉴얼28쪽: 한번 참전한 무장은 자유롭게 교체할 수 있다. 현재 무장 체력0이면 남은 무장이 있어도 패배한다. 이번 변경은 실시간 진행을 구현하지 않는다.

- 이미 참전하여 체력이 남은 무장만 버튼으로 선택한다. 미참전 예비 무장은 기존 자동 지원 규칙으로만 들어온다.
- 대결 전용 참가목록의 기참전 구간을 재배열해 현재 무장을 최고 참전 슬롯에 둔다. 정본 부대 명부는 바꾸지 않는다. 기존 자동 지원의 다음 미참전 무장, 확률, 난수 사용은 그대로다.
- 체력은 무장 ID별로 보존한다. 교체 자체는 합, 투지, 연속방침, 암기 사용을 바꾸거나 체력을 회복하지 않는다. 수치는 기존 단순화 규칙을 유지한 자체 구현이다.
- 저장 v1 구조를 유지하며 교체 직후 같은 자동저장에 기록한다. 반복 교체 로그는 마지막101개 이내로 유지해 복원 상한을 넘지 않는다.

## 검증
- 집중32개, 전체46/46, 구문6파일 검사. R197 대비3시나리오×3seed×150턴 저장 대조9쌍 일치(수동교체 없는 경로).
- 실제 앱 PC 및390px: 왕윤25/여포99 상태에서 여포→왕윤 교체, 새로고침/이어하기, 여포로 복귀. 합1/투지14/정본명부[25,660,173] 불변. 이어하기 전후 저장 전체JSON 동일. 미참전 후성은 후보 제외.
- 위 대결은 엔진 출진 fixture에서 왕윤 체력25와 통제 난수로 기존 지원을 발생시킨 준비 사례다. 자연 대결 또는 물리폰 검증은 아니다. 3인 차기 지원과 반복교체350회/체력0은 엔진 검사다.
- 실시간 진행, 설전 저장 및 모바일 투지 줄바꿈 품질 개선은 미완으로 분리한다. 임시 준비 페이지는 출시 전 삭제한다.
