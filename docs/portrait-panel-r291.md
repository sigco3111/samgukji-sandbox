# R291 비공개 로컬 초상화·패널 후보

## 변경
R290 승인146 정본을 기존514에 더한 로컬660 후보 위에, 폭480px 이하의 열린 패널 뒤로 고정 로그가 비치는 문제만 수정했다. 패널을 닫으면 로그를 다시 표시한다. UI CSS와 캐시 버전 이외 게임 로직·세이브 구조·무장 이름은 바꾸지 않았다.

## 실제 UI 근거
준비된 22턴 저장을 격리된 로컬 브라우저에 넣고 이어하기→메뉴→무장 명부→후성 상세→닫기를 실행했다. R281과 R290의 390px 화면에서 기존 겹침을 재현했고 R291에서는 노란 로그가 카드 뒤로 비치지 않았다. 닫은 뒤 로그 재등장도 픽셀 확인했다. 390×844·480×800에서는 열림 중 hidden, 481×800·844×390에서는 기존 visible이며 두 사각형의 겹침0이다. 네 크기에서 패널 가로넘침이 없었다.

닫기 전후 게임 JSON, 저장 원문, 로그 textContent가 동일하며 페이지 오류0이다. 숨긴 요소의 innerText는 표시문자 측정이므로 보존 판정에 사용하지 않았다. 물리폰·실GPU 검증은 아니다.

## 회귀
기존104개 전체 통과 후 R291 CSS 범위를 고정하는 검사1개를 추가해 최종105/105 통과했다. 기존146 추가·기존514 좌표보존·제외10 부재 검사를 포함한다.

## 보존과 상태
R282 대비 전체 변경 파일과 전체 소스를 별도로 묶었다. 기존 게임 엔진과 시나리오 데이터는 R282와 바이트 동일하다. R290의 Drive ID·해시·아틀라스 출처자료는 별도 보존한다. 원래 저장이나 원격 저장소에 쓰지 않았다. 초상화660은 비공개 로컬 후보이고 공개판은 R258·514 상태다. 원격 전송 중단은 유지한다.
