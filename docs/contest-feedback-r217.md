# R217 일기토·설전 표시 개선 후보

## 범위
- 72px 초상화 무대와 매 합 체력/투지 또는 논리 변화량.
- 변화량은 화면 안의 직전 합 스냅샷으로 계산하며 저장하지 않는다.
- 같은 합에서 방침·필살 대기 등을 다시 그려도 마지막 변화량을 유지한다.
- 복원 직후에는 과거 변화량을 추정하지 않고 다음 합부터 표시한다고 알린다.
- 게임 규칙·AI·시간 간격·저장 형식·원본 데이터는 변경하지 않는다. 애니메이션과 초상화 연결 완성은 이 범위가 아니다.

## 증거
- 전체 66/66 suite, 새 순수 표시 검사 8개 통과.
- 격리된 준비 상태를 이용한 실제 UI. 일기토는 무력 60/60과 난수 .999를 명시한 fixture이다. 자연 발생 증거로 세지 않는다.
- 일기토 1합: 장료 100→96/투지0→14, 상대100→95/투지0→20. 표시와 일치.
- 같은 합 방어 방침 클릭 후 변화량 문구 유지.
- 설전 준비 저장 상태에서 실제 화술 클릭: 논리100→87/100→86. 표시와 일치. 앞선 별도 실행은 반박으로100→91/100이며 서로 다른 난수 결과이다.
- 일기토·설전 전체 저장 문자열이 새로고침 전후 동일. 복원 안내 표시 확인.
- 390×844 및 1280×900 PNG를 직접 검사: 초상화, 수치, 버튼, 안내와 줄바꿈이 화면 안에서 보임. 물리 휴대폰 검증이 아니다.
- js/game.js 바이트 동일, data 변경 0. main/ai/map은 버전 쿼리 연결만 변경.

## 진단 이력
- 첫 설전 검사는 이전 작업으로 진행된 저장을 잘못 골라 pendingDebate가 없어 기다림이 만료됨. 제품 실패로 세지 않고 유효한 준비 저장으로 교체했다.
- PC 설전 캡처 뒤 reload의 wait_until=load가 제한시간을 넘음. domcontentloaded+대상 요소 조건으로 수정 후 390 복원 문자열과 안내를 확인했다.

아직 원격 PR/공개 배포 전 후보이다. 원기획의 연출 전체 또는 게임 전체 완료를 뜻하지 않는다.
