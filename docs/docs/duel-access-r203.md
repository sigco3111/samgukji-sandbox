일기토 규칙·엔진·AI·비용은 변경하지 않는다. 기존 비활성 조건을 투지 필요량/무기·활 명품 필요/암기 사용완료 사유로 표시하고 버튼 접근성 이름과 예약상태를 제공한다. 체력/투지 막대는 이름·범위·현재값을 제공한다. 자동진행 로그는 매합 읽도록 강제하지 않는다. 키보드 시작 후 정지 버튼, 정지 후 시작 버튼으로 포커스를 옮긴다. 폐기된 화면에서 시작하지 않는다.
