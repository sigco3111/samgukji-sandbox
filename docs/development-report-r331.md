# R331 개발 결과의 실제 증가량 표시

상업·농업은 기존 상한100을 유지한다. 기존 로그는 상한 직전에도 이론 증가량을 표시했다. 예: 상업93→100이 +8, 농업97→100이 +8로 표시될 수 있었다. 이제 해당 명령 전후 차이를 표시한다.
